# Karma Video Platform — GitHub Handoff

This repository is intended to be the permanent code backup for the project.

## Important
- Never commit `.env` files or real secrets.
- Use `.env.example` as a template.
- The live database/storage is NOT contained in this repository.
- Keep one permanent backend project and connect future Lovable projects to it.
- Apply database migrations only after inspecting the target backend and current migration state.

## Included
- Frontend application
- Server/backend code
- YouTube/OAuth routes
- Brain/intelligence code
- Production/video architecture
- Supabase migration files
- Documentation and configuration
